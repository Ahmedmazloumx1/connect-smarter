النسخة الحالية بتشتغل على جهازك بحسابات Firebase الحقيقية في مشروعك `connect-smarter-ahmed-2026`. الواجهة Flutter، وخدمة تحليل الـCV هي FastAPI. مفيش مداخل Demo أو حسابات عرض مشتركة في التطبيق.

## البناء والتشغيل

افتح PowerShell وشغّل أمر البناء والفحص:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\ahmed\Documents\Codex\Connect-Smarter-Final\scripts\build-live-web.ps1"
```

بعد رسالة `Live Firebase web build completed` شغّل التطبيق:

```powershell
powershell -ExecutionPolicy Bypass -File "C:\Users\ahmed\Documents\Codex\Connect-Smarter-Final\scripts\start-preview.ps1"
```

افتح `http://localhost:3000/`. لو الخدمات شغالة بالفعل، افتح الرابط مباشرة. بعد أي بناء جديد اعمل تحديث للصفحة. لو عنوان `127.0.0.1` القديم عرض واجهة محفوظة في الكاش، استخدم عنوان localhost المذكور هنا. خدمة الـCV بتشتغل على بورت 8000، والحسابات وحفظ البيانات محتاجين اتصال بالإنترنت.

## الاستخدام

1. سجّل دخولك من **Sign in**، أو أنشئ حساب مرشح أو شركة من الصفحة الرئيسية.
2. كمرشح: كمّل ملفك، ارفع CV بصيغة PDF أو DOCX أو TXT، واستعرض الوظائف المنشورة. التقديم بيتم بعد تأكيد البيانات اللي هتتبعت للشركة.
3. كشركة: انشر وظيفة من حسابك، راجع المتقدمين وغيّر حالة الطلب.
4. تدريب المقابلات بيعرض خمس أسئلة بإجابات مكتوبة، وتقييم لذكر المفاهيم المرجعية، وسجل خاص بحسابك.
5. من **Account settings** تقدر تعدّل بياناتك، تطلب إعادة تعيين كلمة السر، تسجّل خروج أو تحذف الحساب.

اتنقلت ٢٦ وثيقة و٨ حسابات من Firebase القديم، واتحذفت حسابات الاختبار المؤقتة والبيانات المرتبطة بيها. الوظائف القديمة اللي ملهاش مالك محفوظة في قاعدة البيانات، لكنها مش بتظهر كوظائف متاحة للتقديم. تفاصيل النقل في `FIREBASE_MIGRATION.md`.

تحليل الـCV بيستخرج المهارات المذكورة فعلًا؛ مفيش LLM أو تحليل مشاعر أو قرار توظيف تلقائي. البريد بيفتح مسودة في برنامج البريد عندك. ملفات الـCV الأصلية مش بتتحفظ في التطبيق.

التطبيق الحالي نسخة محلية على جهازك. مصدر المشروع متجهز للرفع على GitHub كمستودع Public بناءً على طلبك؛ رفع المصدر مش معناه نشر التطبيق برابط عام. النشر العام واختبارات Android/iOS خطوات منفصلة. تعليمات جهاز جديد موجودة في `README.md`، ونتائج الفحص في `VALIDATION.md`. أدوات المحاكاة وبيانات الاختبار موضحة في `DEVELOPMENT.md` ومنفصلة عن التشغيل العادي.
